```
Marquis Hunting Platform
This document outlines the core features and functionalities for a comprehensive booking and management application.

I. Admin Portal Features
This section covers the configuration and management tools available to the ranch administrator. The system will not be operational for user bookings until these initial configurations are complete.

1. Availability & Date Management
- Booking Calendar: A visual calendar interface to view all current, past, and pending bookings.
- Block Dates: Ability to select and block specific dates or date ranges (e.g., for maintenance, private events, or off-season periods) to make them unavailable for booking.

2. Room & Accommodation Configuration
- Room Management: An interface to add, edit, or remove rooms. Initial Setup: Room 1: 3 Beds; Room 2: 3 Beds; Room 3: 6 Beds.
- Pricing: Set a nightly or per-person cost for each room.
- Whole Ranch Booking: A specific option to set a flat-rate price for booking the entire ranch (all 3 rooms). This can be a fixed price or a percentage discount.

3. Pricing & Services Configuration
- Animal Harvest Fees: Create a price list for each type of animal that can be hunted (e.g., Whitetail Deer: $XXXX, Wild Hog: $XXX).
- Add-on Services: Define optional services with associated costs (e.g., BBQ Night Package: $XXX per group/person; Trailer/ATV Rental: $XXX per day; Guide Services: $XXX per day; Gun Rental: $XXX per day).

4. Legal & Logistics Configuration
- Liability Waiver: A text editor to input, update, and manage the official liability waiver document that users must agree to during booking.
- Booking Buffer/Turnaround Time: Configure the standard check-in and check-out times to manage the buffer between departing and arriving parties (e.g., Check-in: After 3:00 PM, Check-out: Before 11:00 AM).

5. Booking & Guest Management
- Manual Booking: Ability for the admin to manually create a booking on behalf of a guest.
- View Guest Information: Access all submitted information for a booking, including guest details and uploaded licenses.
- Post-Hunt Invoicing: After a hunt is complete, the admin can generate a final invoice by confirming nights stayed, adding all harvested animals per guest, including on-site add-ons/extras, and sending the final itemized receipt to the user's email.

II. User (Hunter) Portal Features
This section covers the booking and information submission process for the guests.

1. Booking Process
- Date Selection: Users view an availability calendar and select check-in/check-out dates. Blocked-off dates are clearly marked unavailable.
- Group Size & Room Selection: Users specify party size and select available rooms.
- Whole Ranch Option: A clear option to book the entire ranch for their party, automatically selecting all rooms.
- Add-on Selection: Users can choose from the list of optional add-ons (BBQ, trailer, etc.).

2. Guest Information & Document Submission
- Personal Details: During checkout, each primary booker must provide: Full Name, Home Address, Contact Phone Number, Date of Birth (or a checkbox adult/youth), Email Address, State Hunting License Number.
- Document Upload: An interface to upload digital copies of required documents, such as a state-issued hunting license.
- Liability Waiver Agreement: Users must read the ranch's liability waiver and digitally agree to the terms before the booking can be submitted.

3. Post-Booking & Post-Hunt
- Booking Confirmation: Upon submitting a booking request, the user receives a confirmation email stating the request is pending final review.
- Final Invoice: After the hunt is completed, the user receives a detailed, itemized invoice via email (accommodation, harvest fees, add-ons).
- Payment: The email contains instructions for payment (e.g., link to payment portal, wire transfer instructions, or pay-by-phone details).

External Services Summary
- Hunter License Validation: Manual by admin / State Wildlife API (if available). Manual photo upload for admin review.
- Communications: Email/SMS services (e.g., AWS SMS, SendGrid, Twilio).
- Database: Relational Database (e.g., PostgreSQL on Amazon RDS).
- Payment Processing: Stripe for post-hunt invoicing and payment (note: could be reused in IGZ).
- Digital Signatures: Documenso for legally binding liability waivers.
- Login from IGZ: Not necessary — completely outside this app's scope.
```
