# Generic Applicability Review — IGZ Marquis Hunting App ("RanchOps Pro")

Every row of `010-GenericTestCases/GenericTestCases.xlsx` (25 worksheets) was evaluated individually against RanchOps Pro's confirmed requirements, per `03-standards/testing-standards.md`'s Exhaustiveness Requirement — no worksheet was bulk-excluded. This document consolidates all 6 worksheet-cluster subagent reviews. `Included in Suite` has been corrected during final assembly for every row whose adapted Generic Test Case was subsequently found to be a cross-document content duplicate (see `FunctionalTestCases.md`'s "Cross-Document Duplicate Resolution" section) — those rows are marked redundant here with a pointer to the surviving test case, rather than appearing as included.

**Revision 2 (2026-11-02) — F-02 fix:** The Test Case Evaluator's first-run `TestCoverageReport_IMHA.md` found that 23 rows removed from the final suite as cross-document duplicates still showed `Applicability Decision = APPLICABLE`, with only `Included in Suite` corrected — misrepresenting why each row was excluded. Each of those 23 rows now carries a distinct `APPLICABLE — EXCLUDED (DUPLICATE)` decision (not `NOT_APPLICABLE`, since the scenario genuinely was applicable; it was excluded only for redundancy with an already-included case), and its Rationale now names the surviving test case. **Also this revision:** `PIN_TC_007`/`FP_TC_019` (password reuse) and `TC_006`/`TC_020` (password complexity) are resolved `NOT_APPLICABLE` — the user confirmed no password rule exists beyond the 8-character minimum; `FP_TC_011` is resolved `NOT_APPLICABLE` (redundant with `TC_GEN_AUTH_004`) on the same basis; and `UR_07` (Cognito invitation-link expiration) is resolved `APPLICABLE` and adapted as new row `TC_GEN_STAFF_002` in `FunctionalTestCases.md` — the user confirmed an expired invitation link simply fails to open.
