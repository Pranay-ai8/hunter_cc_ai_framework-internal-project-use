# SauceDemo Selenium Java Automation

Selenium WebDriver 4.x + Java 17 + TestNG + Maven, Page Object Model (`@FindBy` + `PageFactory.initElements()`) automation suite for [SauceDemo](https://www.saucedemo.com/), generated by the QA-AI-Framework Selenium Automation Orchestrator.

> **Output-location note**: per this run's instructions, all artifacts live under
> `07-outputs/Automation-Selenium/` instead of the orchestrator's literal
> `07-outputs/Automation/` path, to avoid mixing Selenium artifacts with the existing
> Playwright suite already occupying that location.

---

## Prerequisites

- JDK 17
- Maven 3.9+ (no manual driver download needed — WebDriverManager resolves `chromedriver`/`geckodriver`/`msedgedriver` automatically at runtime)
- Google Chrome (or Firefox/Edge) installed locally, or headless mode (default)

## Setup

```bash
cd 07-outputs/Automation-Selenium/Framework
mvn clean install -DskipTests
```

## Environment Configuration

- `-Denv=prd` selects `src/main/resources/config-prd.properties` (SauceDemo has one live public environment — `baseUrl=https://www.saucedemo.com`).
- `-Dbrowser=chrome|firefox|edge` selects the browser (default `chrome`).
- `-Dheadless=false` runs with a visible browser window (default `true` — headless Chrome with `--headless=new --no-sandbox --disable-dev-shm-usage`, safe for a display-less CI/sandbox environment).

## Execution Commands

```bash
# Full suite (all modules, all groups)
mvn clean test -Dsurefire.suiteXmlFiles=config/testng_config.xml -Denv=prd -Dbrowser=chrome

# Smoke only
mvn clean test -Dsurefire.suiteXmlFiles=config/testng_smoke.xml -Denv=prd -Dbrowser=chrome

# Regression only
mvn clean test -Dsurefire.suiteXmlFiles=config/testng_regression.xml -Denv=prd -Dbrowser=chrome
```

Reports: `test-output/ExtentReport.html` (ExtentSparkReporter) and Surefire XML under `target/surefire-reports/`. Failure screenshots: `test-output/screenshots/`. Logs: `test-output/logs/automation.log` (Log4j2).

## Adding a New Page Object

1. Create `../PageObjects/com/codecraft/saucedemo/pages/web/<module>/<Module>Page.java`.
2. Extend `BasePage`; constructor `public <Module>Page(WebDriver driver) { super(driver); }`.
3. Declare locators as `@FindBy` `WebElement` fields (never inline `driver.findElement`).
4. Section banners: `// ==== Locators ====` → `// ==== Validations ====` → `// ==== Page Actions ====`.
5. Route every interaction through `WaitUtils`/the inherited `waitForClickable`/`waitForVisibility` helpers.

## Adding a New TestNG Test Class

1. Create `../Scripts/com/codecraft/saucedemo/tests/<module>/<Module>Test.java`, extending `BaseTest`.
2. One `@Test` method per test case, TC ID referenced in a leading `//` comment.
3. Tag with `groups = {"smoke"}` / `groups = {"regression"}`.
4. Register the class in a `<test>` block in `config/testng_config.xml` (and the relevant smoke/regression suite file if applicable).

## Test Personas (fixed accounts, password `secret_sauce` for all)

|---|---|
| `standard_user` | Fully functional — happy path |
| `locked_out_user` | Login blocked |

| `error_user` | Non-deterministic runtime errors |
