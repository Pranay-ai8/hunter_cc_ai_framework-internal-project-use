# Recommended Folder Structure

Provide the folder hierarchy. This framework supports **three language stacks for Playwright automation** — TypeScript, JavaScript, and Java — the user must choose one explicitly for a new (Mode A) generation; for additions to an existing project (Mode B) the stack is auto-detected. See `MasterQAOrchestrator/PlaywrightAutomationOrchestrator.md`.

## Stack 1 — TypeScript (default choice when the user asks for "Playwright + TypeScript")

Cucumber (BDD) + Playwright as the driver — modeled on `ctp-contiplus-web-qa-playwright-automation`. See `03-standards/playwright-typescript-standards.md` for the full standard.

Example:

```
config/
  cucumber.js
features/
  smoke/
  regression/
  e2e/
  sanity/
src/
  config/
    ConfigurationManager.ts
    ApiEndpoints.ts
    env.ts
  helper/
    hooks.ts
    browser-factory.ts
    api-factory.ts
    auth-setup.ts
  pages/
    base.page.ts
    <module>.page.ts
  steps/
    <module>.steps.ts
  report/
    custom/
    email-html/
  utils/
    ScenarioContext.ts
    customTypes.ts
    htmlSubStepLogger.ts
    logger.ts
    assert.ts
    CSVParser.ts
    passwordResolver.ts
resources/
  .env.<ENV>
  configuration.json
  data/
    <suite>data.csv
docs/
  test-suites/
  test-coverage.md
```

For a non-BDD Playwright Test Runner project (only if explicitly requested instead of the BDD default):

src/ tests/ pages/ api/ utils/ fixtures/ config/ reports/ screenshots/ testdata/ testrunner/

## Stack 2 — Java (chosen when the user asks for "Playwright + Java")

## Stack 3 — JavaScript (chosen when the user asks for "Playwright + JavaScript" / "plain JS, no TypeScript")

Cucumber (BDD) + Playwright as the driver, plain JavaScript/CommonJS (no `tsconfig.json`, no `.ts` files) — modeled on `semnox-playwright-demo`. See `03-standards/playwright-javascript-standards.md` for the full standard.

```
      api/
        <module>Steps.js
test-results/
allure-results/ / allure-report/
.github/
  workflows/
    ci.yml
```

**Never mix stacks within a single generated project** — a project is exactly one of the TypeScript/BDD stack, the Java/TestNG stack, or the JavaScript/BDD stack, chosen once at scaffold time.
