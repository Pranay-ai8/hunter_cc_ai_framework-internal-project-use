# Defect Report Template

## Objective

Generate a comprehensive defect report for all defects identified during test execution.

The report should provide sufficient information for developers, QA engineers, product owners, and stakeholders to understand, reproduce, prioritize, and resolve defects efficiently.

---

# Report Information

- Project Name:
- Application Name:
- Release Version:
- Build Number:
- Environment:
- Report Date:
- Generated By:
- Test Cycle:

---

Provide a summary including:

- Total Test Cases Executed
- Total Defects Logged
- Open Defects
- Closed Defects
- Reopened Defects
- Deferred Defects
- Blocked Defects
- Critical Defects
- High Defects
- Medium Defects
- Low Defects

# Output Quality Standards

Every generated defect report must be:

- Accurate
- Complete
- Reproducible
- Traceable
- Actionable
- Business Focused
- Review Ready
- Executive Ready
- Suitable for defect management tools such as Jira, Azure DevOps, Bugzilla, and ServiceNow.
